Guía de validación de datos en Google Forms

Las validaciones aseguran que los encuestados ingresen datos en el formato correcto. Menos datos mal formateados significa menos tiempo limpiando la hoja de resultados.

Qué es la validación de datos

La validación de datos es una regla que defines para cada pregunta del formulario que verifica el formato de la respuesta antes de aceptarla. Si la respuesta no cumple la regla, el formulario muestra un mensaje de error y no permite avanzar hasta que el encuestado corrija su respuesta.

Por ejemplo, si pides un número de teléfono, puedes validar que contenga exactamente 9 dígitos. Si pides un correo electrónico, puedes validar que tenga el formato correcto con @.

Sin validaciones, los encuestados pueden ingresar datos en cualquier formato: «mi teléfono es el 987654321», «987-654-321», «+51987654321» o simplemente «987654321». Todas son válidas para una persona, pero solo una es fácil de procesar automáticamente.

Cómo activar la validación en Google Forms

  1. Selecciona la pregunta donde quieres agregar validación.
  2. Haz clic en el ícono de tres puntos (⋮) en la esquina inferior derecha.
  3. Selecciona «Validación de la respuesta».
  4. Aparecerán opciones de validación específicas según el tipo de pregunta.

Las validaciones están disponibles para los siguientes tipos de preguntas:

  • Respuesta corta: validación de número, texto, longitud y expresión regular.
  • Párrafo: validación de longitud y expresión regular.
  • Casillas de verificación: validación de cantidad mínima/máxima de opciones seleccionadas.

Validación de texto

La validación de texto permite verificar que la respuesta contenga, no contenga, o coincida con ciertos criterios:

CondiciónUso típicoEjemplo
ContieneVerificar que incluya una palabra claveDebe contener «@» para correos
No contieneExcluir ciertos valoresNo debe contener «test»
Dirección de correoValidar formato de emailAcepta solo formatos válidos
URLValidar que sea un enlaceAcepta solo URLs válidas

Validar correo electrónico

Google Forms tiene una validación integrada para correo electrónico. En la configuración de validación, selecciona «Texto» → «Dirección de correo electrónico». Esto verifica automáticamente que la respuesta tenga formato de email (algo@algo.algo).

💡 Consejo: si solo necesitas recopilar correos, también puedes activar «Recopilar direcciones de correo» en la configuración general del formulario. Esto agrega automáticamente un campo de correo validado al inicio.

Validación numérica

Para preguntas que esperan un número como respuesta, puedes definir rangos y condiciones:

CondiciónEjemploUso
Es númeroSolo acepta dígitosEdad, cantidad, código
Mayor que / Menor queMayor que 0, menor que 150Rango de edad válido
Mayor o igual / Menor o igualMayor o igual a 18Edad mínima
EntreEntre 1 y 100Porcentaje, puntuación
Es número enteroSin decimalesCantidad de personas, productos

Ejemplo práctico: validar edad

Para una pregunta «¿Cuántos años tienes?» donde necesitas que la respuesta sea un número entero entre 1 y 120:

  1. Tipo de pregunta: Respuesta corta
  2. Validación: Número → Entre → 1 y 120
  3. Mensaje de error personalizado: «Por favor ingresa tu edad como un número entre 1 y 120»

Validación de longitud

Controla cuántos caracteres puede tener una respuesta. Esto es especialmente útil para:

  • Comentarios con límite: «Describe tu experiencia en máximo 500 caracteres».
  • Códigos de longitud fija: «Ingresa tu código de 6 dígitos».
  • Respuestas mínimas: «Tu comentario debe tener al menos 50 caracteres» para evitar respuestas vacías como «ok» o «bien».

Configuración: Validación → Longitud → Número mínimo/máximo de caracteres.

Expresiones regulares (regex)

Las expresiones regulares son patrones que definen exactamente qué formato debe tener la respuesta. Son la herramienta de validación más poderosa pero también la más compleja.

Regex útiles para Google Forms

ValidaciónRegexAcepta
Teléfono Perú (9 dígitos)[0-9]{9}987654321
DNI Perú (8 dígitos)[0-9]{8}12345678
RUC (11 dígitos)(10|20)[0-9]{9}20123456789
Solo letras y espacios[a-zA-ZáéíóúÁÉÍÓÚñÑ\s]+María José
Código alfanumérico[A-Z0-9]{6}ABC123
Fecha DD/MM/AAAA[0-9]{2}/[0-9]{2}/[0-9]{4}15/10/2026

Para usar regex en Google Forms:

  1. Selecciona la pregunta de respuesta corta o párrafo.
  2. Activa la validación → Expresión regular.
  3. Elige «Coincide con» para que la respuesta completa siga el patrón.
  4. Escribe el patrón regex.
  5. Añade un mensaje de error claro que explique el formato esperado.

Importante: cuando uses regex, siempre añade un mensaje de error que explique el formato esperado con un ejemplo. «Formato incorrecto» no ayuda al encuestado; «Ingresa tu teléfono como 9 dígitos: 987654321» sí lo hace.

Validación de casillas de verificación

Para preguntas de casillas de verificación (donde el encuestado puede seleccionar varias opciones), puedes limitar cuántas opciones puede marcar:

  • Seleccionar exactamente N: «Selecciona exactamente 3 opciones».
  • Seleccionar como mínimo N: «Selecciona al menos 2 opciones».
  • Seleccionar como máximo N: «Selecciona hasta 5 opciones».

Esto es útil para preguntas como «¿Cuáles son tus 3 prioridades principales?» donde necesitas exactamente 3 respuestas, o «¿Qué días estás disponible?» donde necesitas al menos 1.

Mensajes de error personalizados

Cada validación permite un mensaje de error personalizado. Este texto aparece debajo de la pregunta cuando el encuestado ingresa datos que no cumplen la regla. Un buen mensaje de error:

  • Explica qué está mal de forma específica.
  • Indica qué se espera con un ejemplo concreto.
  • Usa un tono amigable, no acusatorio.

Ejemplos de buenos mensajes de error

Malo ❌Bueno ✅
«Formato inválido»«Ingresa tu teléfono como 9 dígitos, ejemplo: 987654321»
«Error»«Por favor ingresa un número entre 1 y 100»
«Respuesta incorrecta»«Selecciona exactamente 3 opciones de la lista»
«Inválido»«Ingresa una dirección de correo válida, ejemplo: tu@correo.com»

Mejores prácticas de validación

  1. No valides en exceso. Cada validación es una barrera potencial. Si la respuesta es comprensible en cualquier formato, no la valides. Por ejemplo, no valides el formato de un nombre —«Juan Pérez», «JUAN PEREZ» y «juan perez» son igualmente útiles.
  2. Prueba todas las validaciones. Intenta enviar el formulario con datos que deberían ser rechazados y con datos que deberían ser aceptados. Los regex son especialmente propensos a falsos positivos.
  3. Incluye ejemplos en la descripción. Además del mensaje de error, usa el campo de descripción de la pregunta para mostrar el formato esperado: «Formato: 987654321 (9 dígitos, sin espacios ni guiones)».
  4. Prefiere el tipo de pregunta correcto. Si necesitas una fecha, usa el tipo «Fecha» en lugar de «Respuesta corta» con regex. Si necesitas un número, usa validación numérica en lugar de regex.
  5. Considera la experiencia en móvil. Las validaciones con regex pueden ser frustrantes en teléfonos donde es difícil ver exactamente qué se ingresó.

Conclusión

Las validaciones de datos son una inversión que se paga sola: cada respuesta bien formateada que entra es una fila menos que necesitas limpiar en Sheets. La clave es encontrar el equilibrio entre la rigurosidad de la validación y la facilidad de uso para el encuestado. Valida lo necesario, proporciona mensajes claros y siempre prueba con datos reales antes de publicar.
