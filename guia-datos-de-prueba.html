Cómo validar una encuesta con datos de prueba

Los datos de prueba sirven para detectar fallos técnicos, no para fabricar resultados ni reemplazar respuestas de tu público.

Cuando una encuesta es tuya, puedes crear algunos registros controlados para comprobar que la estructura funciona. La clave es que cualquier persona que revise la hoja pueda distinguirlos de las respuestas reales.

Usa una marca clara

Incluye una etiqueta como “PRUEBA” en un campo interno o en el nombre del perfil de prueba. Evita datos que puedan confundirse con una persona real.

Cubre diferentes escenarios

Prepara casos mínimos, completos y con distintas opciones de respuesta. Si tienes secciones condicionales, crea un caso para cada ruta y anota qué esperabas que ocurriera.

Compara lo esperado con lo recibido

Antes de enviar, escribe una pequeña tabla con la respuesta prevista, la sección que debería abrirse y la columna donde debería aparecer. Así puedes detectar errores sin depender de una impresión subjetiva.

Limpia antes de publicar

Elimina las filas de prueba o muévelas a una hoja separada. Si necesitas conservarlas, añade una columna de estado y filtra siempre los registros marcados como prueba al analizar resultados.

Protege la información

No uses datos personales reales para probar un formulario. Utiliza valores ficticios y evita incluir información sensible en campos abiertos.
